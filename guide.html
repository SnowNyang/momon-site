준비물

사이트 주인 계정(SnowNyang)으로 GitHub에 로그인되어 있어야 해요.
로그인이 안 되어 있으면 연필 버튼이 보이지 않아요.

1

저장소에 들어가서 index.html 누르기

주소창에 github.com/SnowNyang/momon-site 를 입력해서 들어간 뒤, 파일 목록에서 index.html 을 눌러요.

github.com/SnowNyang/momon-site
SnowNyang / momon-site
assets
README.md
artmug-embed.js
index.html← 이거 클릭!
2

오른쪽 위 연필 ✏️ 버튼 누르기

파일 내용 위쪽, 오른쪽 끝에 있는 연필 모양 버튼을 누르면 고칠 수 있는 화면으로 바뀌어요.

github.com/SnowNyang/momon-site/blob/main/index.html
momon-site / index.html Raw ⧉ 이거 클릭! ↑
1<!DOCTYPE html><html lang="ko"><head>…
2/* Readability update */
3body{font-size:16px} …
3

Ctrl + F 로 찾기

코드 화면을 한 번 클릭한 다음 Ctrl + F 를 누르고, 검색 칸에 RESERVATION_OPEN 을 입력해요. (맥은 ⌘ + F)
처음 나오는 노란색 줄(1번째 결과)이 바꿀 줄이에요.

github.com/SnowNyang/momon-site/edit/main/index.html
RESERVATION_OPEN1/3↓
5…<div class="status" id="commissionStatus">…
6/* ===== 커미션 상태 설정 =====
7 예약을 받을 때 → 바로 아래 줄 끝을 true 로
8 예약을 안 받을 때 → 바로 아래 줄 끝을 false 로
9*/
10const RESERVATION_OPEN = true;
11const OPEN_TEXT = "예약 접수중";
12const CLOSED_TEXT = "12월 재오픈 예정";
💡 줄 번호는 사람마다 다르게 보일 수 있어요. const RESERVATION_OPEN = 으로 시작하는 줄을 찾으면 돼요.
4

true ↔ false 한 단어만 바꾸기

true 를 지우고 false 를 쓰거나, 반대로 바꿔요. 다른 글자(세미콜론 ; 포함)는 건드리지 마세요.

예약 받을 때
const RESERVATION_OPEN = true;
예약 접수중
예약 마감했을 때
const RESERVATION_OPEN = false;
12월 재오픈 예정
✏️ 문구를 바꾸고 싶을 때는 바로 아래 두 줄의 따옴표 " " 안만 고쳐요.
const CLOSED_TEXT = "2월 재오픈 예정"; ← 이런 식으로요. 따옴표는 지우면 안 돼요!
5

초록색 Commit changes 두 번 누르기

오른쪽 위 초록 버튼 Commit changes… 를 누르면 작은 창이 떠요. 그 창의 초록 버튼 Commit changes 를 한 번 더 누르면 저장 끝!

github.com/SnowNyang/momon-site/edit/main/index.html
momon-site / index.html Cancel changesCommit changes…① 먼저 이거
Commit changes
Commit message
Update index.html
메시지는 그대로 둬도 괜찮아요
CancelCommit changes② 한 번 더!
6

1~2분 뒤 확인하기

사이트에 반영되는 데 1~2분 걸려요. 아트머그 커미션 페이지에서 Ctrl + F5 를 눌러 새로고침하면 바뀐 모습이 보여요.
